# Irfan Writes

DevOps, Cloud, and Technology Blog

Live at: https://irfancode.github.io

## Writing a Post

Create a new file in `_posts/` with the format: `YYYY-MM-DD-title.md`

Example frontmatter:

```yaml
---
title: "My New Post"
date: 2026-03-31
category: "DevOps"
tags: ["Cloud", "Automation"]
---

Your content here...
```

GitHub Pages will automatically build the site using Jekyll.
